# نظام إدارة المخزون والمبيعات — Mini ERP Stock & Sales

نظام ويب داخلي متكامل ومحكم لإدارة المنتجات، المستودعات المتعددة، أرصدة المخزون، دفتر أستاذ حركات المخزون، فواتير المبيعات، حركات الإلغاء العكسية، التقارير التشغيلية والمالية مع تصدير CSV المتوافق مع Excel العربي، وسجل التدقيق المركزي.

> [!WARNING]
> **تنبيه هام:** البيانات المرفقة في ملفات التأسيس هي **بيانات تجريبية لأغراض الفحص والاعتماد (Demo Data)**، وليست بيانات إنتاجية. لا تُنفذ ملفات التأسيس على قواعد بيانات تحوي بيانات حية.

---

## 1. التقنيات والميزات المعتمدة (Tech Stack & Features)

- **إطار العمل:** CodeIgniter 3.1.13 بمعمارية MVC الصارمة وخدمات الأعمال المركزية.
- **لغة البرمجة وبيئة التشغيل:** PHP 7.4+ متوافق ومختبر على PHP 8.2.12 تحت بيئة Windows + XAMPP.
- **قواعد البيانات:** MariaDB 10.4.32 / MySQL 8.0+ بمحرك `InnoDB` وترميز `utf8mb4_unicode_ci`.
- **الواجهة الأمامية:** HTML5, CSS3, JavaScript, jQuery, AJAX, Bootstrap 5 RTL مع دعم كامل للغة العربية.
- **العملة ونوع الكميات:** الريال السعودي (**SAR**) حصراً، والكميات أعداد صحيحة (**Integers**) مع منع تام للرصيد السالب.

### أبرز ميزات النظام:
1. **الأدوار والصلاحيات (RBAC):** 3 أدوار ثابتة ومفحوصة خادمياً (`admin`, `warehouse`, `sales`).
2. **البيانات الأساسية:** تصنيفات، مستودعات بكود فريد، بطاقات منتجات بـ SKU فريد، والتعطيل الناعم بدل الحذف.
3. **دفتر أستاذ المخزون:** حركات تراكمية تاريخية غير قابلة للتعديل (`in`, `adjustment`, `sale`, `sale_reversal`).
4. **فواتير المبيعات وحمايتها:** حسابات الإجماليات بالسيرفر، لقطات الأسعار التاريخية، وترقيم تسلسلي يومي ذري.
5. **إلغاء الفواتير (F08):** حصر الإلغاء بالمدير، توثيق السبب، استعادة المخزون بحركات عكسية ذرية، ومنع الإلغاء المزدوج.
6. **التقارير الإقليمية (F09):** 5 تقارير مع بطاقات مؤشرات الأداء، وتصدير CSV متوافق مع Excel العربي (فاصل منقوط و UTF-8 BOM).
7. **سجل التدقيق المركزي (F10):** مسار تدقيق للأحداث الحساسة، حجب كلمات المرور والأسرار، وتراجع ذري شامل عند الفشل.

## 2. متطلبات التشغيل (System Requirements)

- **خادم الويب:** Apache 2.4+ (متوفر عبر حزمة XAMPP).
- **إصدار PHP:** PHP 7.4 إلى PHP 8.2 مع امتدادات `mysqli`, `mbstring`, `json`, `session`.
- **قاعدة البيانات:** MariaDB 10.4+ أو MySQL 8.0+.
- **المتصفح:** أي متصفح حديث (Chrome, Edge, Firefox).

## 3. خطوات التشغيل السريع (Quick Start)

1. **وضع المشروع في XAMPP:**
   تأكد من وجود المجلد في المسار:
   `C:\xampp\htdocs\codeigniter-projects\mini-erp-stock-sales`
2. **تشغيل الخوادم:**
   افتح لوحة تحكم XAMPP وشغّل خدمتي **Apache** و **MySQL**.
3. **إنشاء قاعدة البيانات:**
   أنشئ قاعدة بيانات جديدة باسم `mini_erp_stock_sales` بترميز `utf8mb4_unicode_ci`.
4. **استيراد المخطط الهيكلي الكامل:**
   استورد الملف: [`database/schema_full.sql`](database/schema_full.sql).
5. **استيراد البيانات التجريبية:**
   استورد الملف: [`database/seed_demo_data.sql`](database/seed_demo_data.sql).
6. **فتح التطبيق وتسجيل الدخول:**
   توجه إلى الرابط: `http://localhost/codeigniter-projects/mini-erp-stock-sales/`
