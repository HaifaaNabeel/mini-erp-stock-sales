**العملة المعتمدة:** الريال السعودي (SAR)
**الحسابات التجريبية المعتمدة للاختبار:**
- **المدير:** `admin` / `Admin@123456`
- **أمين المستودع:** `warehouse_user` / `Warehouse@123456`
- **مسؤول المبيعات:** `sales_user` / `Sales@123456`

## إرشادات للمختبرين (Tester Guidelines)
- يتم تنفيذ كل حالة اختبار بالترتيب الموضح في الجداول أدناه.
- الحقول **«النتيجة الفعلية (Actual Result)»** و **«حالة الاختبار (Status)»** تُركت فارغة عمداً لكي يقوم المختبر بتدوين ملاحظاته وحالة الاختبار (ناجح / فاشل) عند الفحص الفعلي.
